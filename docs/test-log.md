# 试玩记录（Tested）

评分里"测过"要的是证据，不是一句"我们测了"。这张表每周五填一次，第 3 周至少 3 个人。

## 怎么测

1. 让同学自己坐下，**不要提示任何按键**，只说一句："随便玩，被抓了也没关系。"
2. 你在旁边只做三件事：掐表、记他卡在哪、记他笑在哪。
3. 他卡住超过 15 秒才提示，提示内容写进"卡点"。
4. 测完问三个问题：哪里没看懂？哪里最好笑？还想再玩一次吗？
