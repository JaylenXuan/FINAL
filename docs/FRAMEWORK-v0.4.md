## A. 常驻小地图（GTA5 风格）

### 位置与形态

- **一直显示在左上角**，不只在死亡时出现
- 圆角矩形，参考 GTA5 的雷达：深色半透明底、细白边、道路用亮线、锚点用图标
- 尺寸：常态 220×220；死亡选点时放大到 320×320
- 顶部一个小 `N`，角色用一个会转的箭头表示朝向

### 地图内容

- 由 `world.json` 的 building / room 矩形直接生成 SVG 俯视图，不手画
- 三档颜色：地面（深灰）、建筑（更深的块）、道路/广场（亮线）
- 四个锚点图标：教室、连廊、图书馆、广场
- 玩家箭头跟着 `player.yaw` 转

### 死亡时

```
死亡 → 全屏压黑到 95%
     → 只有左上角地图保持全亮（并且放大）
     → 地图上四个锚点开始脉冲
     → 键鼠选点，确认
     → 地图缩回常态，0.3s 淡入，醒来
```

- 除地图外，屏幕只剩中间一行大字（CAUGHT / WRONG）
- 不弹独立列表、不刷新页面

### 参考要点（GTA5 雷达）

- 圆角矩形 + 细边，不是圆形
- 底是深蓝灰，不是纯黑
- 道路是浅色细线，建筑是色块
- 图标有颜色区分，选中项放大 + 外圈
- 玩家箭头始终朝上或跟着朝向转，二选一；我们用“跟着朝向转”

### 成本与验收

- 成本：**7–9 小时**（SVG 生成 2h、常驻挂载 1h、投影 1h、死亡选点 2h、视觉打磨 2h）
- 验收：
  - 正常游玩时地图一直在左上
  - 死亡后除地图外全黑
  - 键鼠都能选，3 秒内完成
  - 选中项有名字和放大反馈

## B. 下课聊天

已确认要做，**聊天内容之后再定**，先把框架留出来。

```
靠近同学 (<2m) → HUD 提示 "E  Talk"
→ 按 E：同学转向你，头顶气泡 1.5s
→ 字幕一句
→ 按 E 结束 / 5s 自动结束
```

- 三个同学：鲸鱼娘、奶龙、奶蛙，各一句
- 台词先放在 `lines.json` 的 `CM_1/2/3`，内容之后替换
- 复用 `interactables`、`hud.subtitle`、`player.pos`
- 边界：两人靠近取最近；被追/答题时禁用；重复对话换备用句；走开自动结束
- 成本：**约 5 小时**

## C. 同学模型

### 鲸鱼娘（已下载）

- 文件：`public/models/characters/deepseek-reset.vrm`（12.45 MB）
- 来源：npm 包 `dsh-plugin-whale-mate@0.6.3`，原作者 B站 **@hihihihi202**
- 许可：**署名、非商用、允许修改**；本课程项目非商用，报告和 `CREDITS.md` 必须署名
- 加载：需要 `@pixiv/three-vrm`（MIT），`GLTFLoader` + `VRMLoaderPlugin`
- 限制：长裙**不能坐**，所以鲸鱼娘站着，或半靠在桌边
- 成本：接入 2h、摆位 1h

### 奶龙 / 奶蛙

- 现状：网上只有 **STL / 3MF 打印模型**（crealitycloud、cgmodel），没有带骨骼和贴图的游戏模型
- 做法：STL → Blender 减面 → 导出 GLB → 顶点色上色 → 当**静态同学**（整体轻微上下浮动，不做走路）
- 风险：粉丝二创，版权归原作；课程非商用可以，但**不要公开传播模型文件**
- 成本：每个 2–3h（减面 + 上色 + 摆位），两个 4–6h

### 备选（如果 STL 效果太差）

用 2D 立牌：PNG 透明贴图 + 始终面向相机。1 小时一个，风格反而统一。作为兜底，不做首选。

## D. 关于 GTA 逆向工程

`re3` / `OpenRW` 是 C++ 写的原生引擎，**换语言解决不了问题**：

1. 它们依赖 GTA 原版游戏资源（地图、模型、音频），这些资源有版权，不能随项目分发
2. 浏览器里跑不了原生 C++；用 Python 重写等于重写整个引擎，不是几周能完成的量
3. 我们要的是“GTA 的手感”，不是“GTA 的代码”；手感用相机、追逐、通缉、黑屏就能做出来

结论：继续用 three.js 自己写，不碰逆向工程。
