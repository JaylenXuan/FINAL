## A. 死亡 → 地图选点

### 目标

黑屏之后不是弹一个列表，而是**只剩左上角一张地图还亮着**，玩家在地图上点锚点重生。地图像 GTA5，选点像原神。

### 流程

```
死亡 (Caught)
  → 全黑 0.8s，中间一行大字（CAUGHT / WRONG）
  → 黑幕退到 92%，只有左上角地图亮
  → 选锚点（键鼠都行）
  → 确认，0.3s 淡入
  → 醒来（教室完整版 / 其他简化版）
```

### 视觉规格

| 元素 | 规格 |
|---|---|
| 地图位置 | 左上，距边 24px |
| 尺寸 | 320 × 320，圆角 8px |
| 底色 | `rgba(10,12,16,.92)`，1px 白边，外发光很弱 |
| 内容 | 俯视平面图：广场、教学楼、三个房间的相对位置 |
| 锚点 | 4 个图标，未选为灰色，选中为白色 + 外圈 |
| 选中态 | 图标放大 1.15，旁边出现名字（Genshin 式） |
| 其余区域 | 纯黑，只留一点暗角 |
| 顶部 | 一个很小的 `N` 和当前区域名 |

### 交互

- `1–4`：直接选对应锚点
- 方向键：在地图上移动高亮
- 鼠标：悬停高亮，点击选中，再点一次确认（或 Enter）
- 选中 / 确认各有一次轻音效
- 不弹独立窗口、不刷新页面

### 数据

- 复用 `world.anchorList`（id / label / pos）
- 地图不用画：从 `world.json` 的 building / room 矩形直接生成 SVG 俯视图，颜色只用三档
- 坐标投影：`(x - minX) / (maxX - minX) * 320`

### 状态机

现在是 `Caught → ChooseAnchor → WakeUp`，把 `ChooseAnchor` 的 UI 从列表换成地图即可，状态不变。

### 成本与验收

- 成本：**6–8 小时**（地图 SVG 2h、投影 1h、交互 2h、视觉打磨 2h）
- 验收：
  - 死亡后除了左上角，屏幕全黑
  - 键鼠都能选，3 秒内完成
  - 选教室是完整醒来，选其他是简化醒来

## B. 下课聊天

### 目标

答对下课之后，教室里有三个同学，可以走过去按 `E` 聊一句。不做对话树，只做“一句一梗”。

### 流程

```
靠近同学 (< 2m)
  → HUD 出现提示 "E  Talk"
  → 按 E：同学转头看你，头顶冒一个气泡（1.5s）
  → 字幕出一句台词
  → 按 E 结束；或 5 秒自动结束
```

### 数据

```json
"classmates": [
  { "id": "cm_1", "pos": [-3, 0, 1], "yaw": 0, "line": "CM_1" },
  { "id": "cm_2", "pos": [3, 0, 1], "yaw": 0, "line": "CM_2" },
  { "id": "cm_3", "pos": [0, 0, 3], "yaw": 180, "line": "CM_3" }
]
```

台词已经在 `lines.json`：

- `CM_1`：听说走路要刷手机
- `CM_2`：我睡了一整节课，作业是什么
- `CM_3`：掰手腕？来啊

### 复用现有模块

| 需要 | 用现成的 |
|---|---|
| 触发范围 | `world.interactables`（门已经在用，加一个 `type: "npc"`） |
| 字幕 | `hud.subtitle(line, dur)` |
| 玩家位置 | `player.pos` |
| 区域判断 | `player.zone === 'classroom'` |
| 输入 | `input.once('KeyE')` |

### 边界情况

| 情况 | 处理 |
|---|---|
| 两个同学都在 2m 内 | 取最近的那个 |
| 正在被追 / 答题中 | 禁用 E |
| 重复对话 | 第二次换一句备用台词（每人两句） |
| 说话时走开 | 直接结束，不锁输入 |
| 同学背对你 | 转头朝你，0.2s 插值 |

### 成本与验收

- 成本：**约 5 小时**（三个同学摆位 2h、交互 2h、气泡 1h）
- 验收：
  - 三个同学各能聊一句
  - 不锁移动，不打断手机 bit
  - 对话结束能立刻再触发

## C. 同学模型：搜索结果

### GTA 开源项目

| 项目 | 语言 | 能不能用 |
|---|---|---|
| re3 / OpenRW | C++ | 不能。GTA 逆向工程，桌面程序，且 re3 被 DMCA 下架过 |
| 各种 “GTA in one HTML” | JS | 没有能跑的，找到的那个仓库 404 |

**结论**：没有可用的 Web GTA 模板，继续用自己的代码。

### 动漫角色模型

| 来源 | 格式 | 许可 | 适合 | 风险 |
|---|---|---|---|---|
| [Quaternius Universal Animation Library](https://quaternius.itch.io/universal-animation-library) | glTF | **CC0** | 低多边形同学 + 坐下/说话/挥手动画 | 风格偏卡通，但和现在的胶囊最接近 |
| VRoid / BOOTH 的 VRM | VRM | 每个模型单独授权，底模多为 CC0 | 动漫风，表情丰富 | 要加 `@pixiv/three-vrm`，坐姿要调骨 |
| `deepseek-reset.vrm`（whale-mate 插件） | VRM | 署名 B站 @hihihihi202、非商用、可改 | 鲸鱼娘 | 长裙不能坐，必须署名 |
| 奶龙 / 奶蛙 粉丝模型 | STL/OBJ | 不明确，IP 有版权 | 梗最足 | 不建议进项目 |

**推荐**：同学先用 **Quaternius CC0 低多边形**，三个人换颜色就够；想更动漫再上 VRM。奶龙这类不建议，版权说不清。
