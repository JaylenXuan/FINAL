## S0 会被卡住的

### 1. `three-player-controller` 不是装上就能跑 [阻断]

`npm i three-player-controller@0.6.3` 能装（peerDependencies: `three>=0.159.0`、`three-mesh-bvh>=0.7.8`），但它的
`PlayerControllerOptions` **强制要求 `playerModelConfig`**，里面要 `idleAnim / walkAnim / runAnim / jumpAnim`
四个**动画名**——也就是说：没有带这些命名片段的 GLB 角色，`init()` 起不来。

它还自带一套碰撞世界（`ColliderDesc` / `BoxShape` / `MeshShape` / `addCollider` / BVH worker），
也就是说 `world/builder` 的碰撞盒产出格式要**为它改一遍**，不是"塞进去就能用"。

**建议**：W0 给它 4 小时上限，验收标准只有一条——胶囊能在 `world.json` 生成的盒子里走、不穿墙。
过期就转自写控制器（+10h，正好吃掉 §15 的备案），并把 `world/builder` 的碰撞盒格式定为
`{min, max}` AABB（本项目原型已按这个跑通，`src/player/player.js` 里是圆 vs AABB 推出）。

### 2. `room.camera.pos` 是局部坐标还是世界坐标，没写 [阻断]

规格 §6 示例：`"origin": [100,0,0]` 配 `"camera": { "pos": [6,5,8] }`。
如果 `pos` 是世界坐标，`[6,5,8]` 就在广场上，不在教室里——只能是**相对 origin 的局部坐标**。
更坑的是 `[6,5,8]` 在一个 `10×8×4` 的房间里本身就在**房间外面**（z=8 越过 z=±4，y=5 越过高 4），
第一版实测拍到的就是教室盒子的外壳。

**建议**：把"camera.pos / lookAt 相对 origin"写进 §6 规则；`world/builder` 里加越界告警
（已实现，见 `src/world/builder.js` 的 `[builder] … 落在房间外面`）。A 填机位时按"站在房间内部看"来填。

### 3. 连廊在数据里没有位置 [阻断]

§2 要做连廊，§6 的 `rooms` 示例只有 classroom / library，而 `a_corridor` 又被塞进了 `outdoor.anchors`
——连廊是室内空间，锚点却在室外列表里，互相矛盾。

**建议**：连廊也是一条 `rooms` 记录。原型里用 `shell: "room_3x8x3.8"`（3m 宽 × 8m 长 × 3.8m 层高），
`builder` 按"最短边 < 4m 视为走廊"自动两端敞开、两侧开窗。**这条要 A 确认**，因为它决定 A 怎么填 `shell`。

### 4. 门 → 房间的对应关系没有字段 [阻断/需确认]

`world.json` 的 prop 只有 `type / pos / rotationY`，没有"这扇门通向哪个房间"。
原型用 prop 的 type 约定：`door_classroom` / `door_library`，type 后缀即目标房（`world/props.js` 注册表里登记）。
**（已拍板否决这个做法：改用 `type:"door"` + `to` 字段，见上方状态 ③。）**
**这算不算改 schema 由你们定**：如果嫌脏，就在 prop 上加一个 `"to": "a_classroom"` 字段——那是改 schema，要走 CHANGELOG + 两人确认。

## S1 会影响排期的

### 5. 校长的速度写成了两个互相矛盾的数 [阻断 demo 逻辑]

§9："速度是玩家走路的 1.05 倍、跑步的 0.6 倍"。按本项目的 3.2 / 6.0 m/s 算，两个数分别是 **3.36** 和 **3.6**，不等。
更要紧的是：**玩家一按住 Shift（6.0）就永远追不上**，那 bit 1 的"必然死亡"就不成立了。

**建议**：三个数定死一个组合。参考做法，二选一：
- 追不上就追不上：加"丢失"规则（出视线 3 秒 → 校长放弃、星保留、bit 复位），代价是要写 §4 里那个"丢失"分支；
- 必被抓：校长速度 = 3.6，玩家跑 6.0 能拉开但广场只有 20m，跑到边界就被逼停 → 靠"跑不掉"制造压迫感。
原型现在按 3.36 跑（追不上），所以 `?spawn=1` 只是站桩验比例。

### 6. 冷却 / 复位的默认值全是 TBD，但没有兜底规则

`bits.json` 里 `cooldown: "TBD"`，规格说"不要自己编数值"。可运行代码必须有行为。
原型做法：**死亡后整条 bit 复位、无冷却**（`bits.reset()`），并在 `docs/DEV-NOTES.md` 记了一笔。
建议在 §9 补一句："cooldown 未定期间视为无冷却，死亡后复位"，这样代码和文档不打架。

### 7. 课堂 bit 的节奏没定

"答错 → 违纪星 +1 → 回到再被点名"：间隔多久？选项每次是否一样？答对之后这条 bit 是结束还是可以再来？
原型：每次 3 秒后重新点名、选项固定、答对即结束（`phase='done'`），再次在教室醒来会重新武装。
这些需要一次明确的书面决定，否则第 3 周试玩时会被问住。

### 8. 第 3 颗星的来源没定

§10 说"其他来源【暂定】"。现在只有"玩手机"和"课堂答错"两个来源，而课堂那条本身就是"3 星逐出"，
所以第 3 颗星在广场路径上永远到不了 → 上限 3 在广场只是个装饰。要么加来源（迟到 / 跑进草坪 / 在连廊喧哗），
要么承认"广场路径永远只有 1 星"。

### 9. 文案没有清单，也没有指定人

`lines.json` 只有 2 条，但流程至少还要：`warn` 喊话、`chase` 喝止、老师点名、3 个选项、答对、答错、
`CAUGHT` 大字（标题 + 副标题）、4 个锚点名、HUD 提示、`F`/`R` 的兜底提示。
§17.2 说"先定一个人"但没定——建议**写的人与润色的人分开**（非母语润色最花时间）。

### 10. 音频只有目录，没有来源与格式约定

§3 说"音频用 WebAudio"，§8 把 `public/audio/` 划给 B，但没写：文件格式（.ogg 还是 .mp3）、
是否允许合成音、单声道/采样率、包大小上限。原型全部用 WebAudio 合成
（`src/audio/audio.js`：星、警报、闷响、耳鸣），好处是零素材零加载，缺点是"不够校园"。
建议：环境音 + 耳鸣走合成，脚步 + 警报用人声/实录素材（现场 3-4 分钟，声音比画面更影响观感）。

### 11. 性能没有量化红线

"合并几何、控制 draw call"没法验收。建议定：**draw call < 150、三角面 < 15 万、1080p 稳定 55fps 以上**，
并在 W3 冻结前用 `renderer.info` 打一次卡（代码里 `window.__campus` 已经挂在控制台了，可以直接 `renderer.info` 看）。

## S2 交付物与演示的漏洞

### 12. "AI 使用说明"是交付物，但没有任何要求

四个交付物里它最容易欠账。建议第一天就建 `docs/AI-LOG.md`，每次 AI 协作追加三行：
**让它做什么 / 它给出的关键代码在哪 / 你改了什么**。报告里可以直接剪。

### 13. "测过（含一位同学试玩）"需要证据

评分项明写"测过"，§17.5 说"记卡点、笑点、耗时"但没有表结构。建议 `docs/test-log.md` 固定表头：
`日期 / 试玩者 / 版本 commit / 是否触发 bit1 / 是否触发 bit2 / 卡点 / 笑点 / 全程耗时 / 结论`。
三个同学 × 一列"卡点"就是报告里最硬的一页。

### 14. 仓库细节没写

`.gitignore` 要含 `node_modules/ dist/ .tmp/`；素材如果超过 50MB（Mixamo 的 GLB 很容易），
要么开 LFS 要么只提交压缩后的；`CHANGELOG.md` 两人同时改必冲突，约定"只追加，不改别人的行"。

### 15. 截止日期未公布前，W4 要留 buffer

§17.6 说 W4 不可压缩。如果实际只有 4 周，先砍的应该是**图书馆门厅**（它现在只有一个 bit 都没定的空壳），
而不是连廊——连廊是"校园感"最强的镜头。

## 已经由原型验证过、不用再吵的点

- 固定 60Hz 逻辑 + 渲染插值：`src/core/loop.js`，切标签页回来不会瞬移（`real>0.25` 截断）
- 五态状态机拦非法跳转：`Caught → WakeUp` 会被拒绝并 `console.warn`
- 死亡流程总时长：定格 0.3 + 黑屏 0.8 = 1.1s，加选点后进醒来，**远在 3 秒内**
- 远处房间（x=100/200/300）与雾共存的问题：室内必须关雾，`applyZoneFx()` 已按区域开关
- 相机偏移 `[0,6,9]` 会把镜头推到地平面之外，地面要比 `bounds` 大一圈（原型用 26×26 包 20×20 的 bounds）
