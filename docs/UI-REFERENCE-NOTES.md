# 参考拆解：VINCENT 星光之间 → 校园项目可借用清单

> 读的是 `Desktop\比赛\借鉴素材\01-VINCENT星光之间-拆解与借鉴.md`。
> 它证明两件事：**首屏交给 DOM、重场景后置**；**两色 + 档案语法**能把 3D 项目做得像作品。
> 我们能借的是结构与语法，不是泛光和粒子。

## 一、可直接借用（按性价比）

| # | 借用点 | 落到我们哪 | 成本 | 收益 |
|---|---|---|---|---|
| 1 | **首屏 DOM 化** | 标题卡加「进入校园」按钮，点击后才初始化 Three；WebGL 失败时显示说明 | 2–3h | 评委第一眼永远有东西；顺带遮住 VRM 冷启动 |
| 2 | **两色纪律** | HUD 只留 ink + accent；星/警报用 accent，说明用 muted | 1–2h | 界面立刻从“工程稿”变成“有设计” |
| 3 | **四角信息条** | 左上课程/组名，右上“非官方课程作业”，左下操作提示，右下 build hash | 0.5h | 极低成本的身份感 |
| 4 | **档案语法** | 题卡、死亡屏加 1px 边 + 四角 L 形短线；死亡屏标题用 `01 / WRONG` | 1h | 和“记过/通报”的设定一致 |
| 5 | **编号化** | 8 间教室门牌 01–08；锚点 1–4 已有 | 0.5h | 让 8 间房像目录，不像复制 |
| 6 | **相机退路** | 加“自动跟拍”模式，按 C 切换 | 3h | 演示时可当自动巡游，也解决“不会走” |
| 7 | **加载叙事** | boot 文案从 `loading campus` 改成两句 | 0.3h | 冷启动那 2 秒不空白 |
| 8 | **CanvasTexture 写字** | 黑板字、讲台牌、公告栏用 2D canvas 画中文再贴图 | 1h | 不用建模字体，中文随便写 |

## 二、不要抄

- **Bloom / 粒子 / 钢琴 / 949KB 主包**：题材与性能都不符，我们还要在集显笔记本上跑。
- **全屏 3D 首屏**：我们冷启动本来就重（VRM 12MB），正好反过来——首屏越轻越好。
- **“可信”不是“震撼”**：课程项目评委看的是完成度与可解释性，不是氛围。

## 三、映射到现有屏幕

| 屏幕 | 现状 | 借用点 |
|---|---|---|
| 开场 | `#intro` 标题卡，3.6 秒自动消失 | 1、3、7 |
| HUD | 星、区域、冲刺、提示、字幕，多色 | 2、3 |

| 死亡屏 | `#black` + 大字 | 4、5 |
| 8 间教室 | 门牌 01–08，内部靠配色 | 5、8 |
| 地图 | 常驻雷达 + 死亡放大 | 5（编号） |

## 四、结论

先做 **1 + 2 + 8**：首屏 DOM 化、两色纪律、CanvasTexture 写字。三件加起来 4–6 小时，对“作品感”的提升最大，且都不碰核心逻辑。
